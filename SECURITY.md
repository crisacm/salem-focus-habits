# Security Policy

## Supported versions

Salem has no releases yet. For now, only the latest code on the `develop`
branch is supported.

## Reporting a vulnerability

Please **do not report security vulnerabilities through public issues,
discussions or pull requests.**

Instead, use GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/crisacm/salem-focus-habits/security) of this
repository and click **Report a vulnerability**.

Please include:

* A description of the problem and its potential impact.
* Steps to reproduce it.
* The affected version or commit, and the platform (Android or iOS).

Salem is maintained by volunteers, so we cannot offer a bug bounty or a
guaranteed response time, but we will do our best to acknowledge your report
and to fix confirmed issues as soon as possible.

## Issues in the original project

Salem is based on [Loop Habit Tracker](https://github.com/iSoron/uhabits). If
the vulnerability is in code inherited from the original project and also
affects it, please consider reporting it to that project as well.
