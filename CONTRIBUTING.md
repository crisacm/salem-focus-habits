# Contributing to Salem

Thank you for your interest in contributing! Salem is an open source project
and contributions of all kinds are welcome. Salem is a fork of
[Loop Habit Tracker](https://github.com/iSoron/uhabits) by Álinson Santos
Xavier, and it builds on the work of that project's contributors.

## Ways to contribute

* **Report bugs.** Please [open an issue](https://github.com/crisacm/salem-focus-habits/issues/new/choose)
  using the bug report template.
* **Share ideas and ask questions.** Use [GitHub Discussions](https://github.com/crisacm/salem-focus-habits/discussions).
* **Write code.** Android, Jetpack Compose, Kotlin Multiplatform and iOS
  contributions are all welcome.
* **Improve the documentation.**
* **Translate the app.** Translations are not set up yet; if you would like to
  help, please open an issue.

## Getting started

1. Fork the repository and create a branch from `develop`.
2. Build the project following [docs/BUILD.md](docs/BUILD.md).
3. Run the tests as described in [docs/TEST.md](docs/TEST.md).
4. Open a pull request against the `develop` branch. The pull request template
   will guide you through the checklist.

The details about pull requests, code style, branching and the release process
are in the [developer guidelines](docs/GUIDELINES.md). In short: keep pull
requests small and focused, discuss large features before writing them, and
share a mockup first for user interface changes.
